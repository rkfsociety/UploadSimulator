# Upload Simulator

## Дорожная карта

- перевести размеры и скорости в UI полностью на **байты** (сейчас часть логики ещё в МБ);
- сохранение прогресса;
- перетаскивание и снятие модулей с поля;
- новые типы текстовых файлов и лимиты канала.

Казуальная игра про **передачу файлов в сети**: скачиваешь данные из интернета на диск, затем выгружаешь их обратно. Собираешь пайплайн из модулей на карте и зарабатываешь на выгрузке.

**Базовый объект** — обычный **текстовый файл**.  
**Стартовая скорость** передачи (скачивание и выгрузка на 1-м уровне модулей) — **100 байт/с** (далее растёт с улучшениями блоков).

Стек: **Godot 4.3+** (GDScript). Один проект собирается на **Windows** и позже на **Android** без переписывания логики.

Игра в **портретной ориентации** (720×1280): на ПК окно вертикальное, на Android экран зафиксирован в portrait.

## Суть игры

1. **Скачивание** — модуль «Загрузчик» тянет файлы из сети в «Хранилище» (нужна цепочка проводов на поле).
2. **Выгрузка** — «Аплоудер» отправляет файлы из хранилища в сеть; доход копится в сейфе аплоудера.
3. **Касса** — «Коллектор» переводит деньги с аплоудера в общую кассу (покупки и улучшения).

Источник файлов на старте — **студия** (создаёт текстовые файлы на «носителе» перед скачиванием). Это не симулятор ютубера: нет просмотров, подписчиков и монтажа роликов — только **download → storage → upload → money**.

## Быстрый старт (ПК)

1. Установи [Godot 4.3+](https://godotengine.org/download) (рекомендуется стандартная сборка).
2. Открой папку проекта: **Project → Import** → укажи `project.godot`.
3. Нажми **F5** (Play) — запустится главная сцена.

### Управление

| Действие | Как |
|----------|-----|
| Карта | Перетаскивание — панорама, колесо / pinch — зум. Кнопка **◎** справа внизу — центр карты |
| Магазин | Кнопка с иконкой корзины снизу — покупка модулей; после покупки модуль ставится в центр экрана |
| Поле | Модули **6×4** клетки; соедини порты проводами |
| Пайплайн файлов | **Загрузчик → Хранилище → Аплоудер** (файлы), **Аплоудер → Коллектор** (деньги) |
| Порты | Круг = файлы, квадрат/ромб = деньги. Загрузчик↔аплоудер и загрузчик↔коллектор напрямую нельзя |
| Провода | Клик по выходу, затем по входу. Повтор по выходу — снять провод |
| Студия | Запись текстового файла на носитель (тратит энергию) |
| Скачать | На загрузчике — «На диск»: файл из сети в хранилище |
| Выгрузить | На аплоудере — отправка файла из хранилища в сеть |
| Деньги | «Собрать в кассу» на коллекторе |
| Улучшения | Кнопка **↑** на модуле — быстрее передача и больше ёмкость диска |

**Старт:** касса $370 (стоимость базового комплекта модулей), по одному модулю каждого типа на складе. Провода игрок прокладывает сам.

## Сборка под Windows

1. **Project → Export…**
2. Выбери пресет **Windows Desktop** (уже в `export_presets.cfg`).
3. При первом запуске Godot попросит скачать export templates — согласись.
4. **Export Project** → файл появится в `build/UploadSimulator.exe`.

Из командной строки (если `godot` в PATH):

```bash
godot --headless --export-release "Windows Desktop" build/UploadSimulator.exe
```

## Сборка под Android (когда понадобится)

1. Установи **Android SDK**, **JDK 17** и пропиши пути в Godot:  
   **Editor → Editor Settings → Export → Android**
2. Создай debug keystore (Godot может сделать это сам при первом экспорте).
3. **Project → Export… → Android → Export Project**.
4. Установи APK на телефон или эмулятор.

Рендерер проекта: `gl_compatibility` — стабильный вариант для мобильных GPU. UI масштабируется (`canvas_items`) + touch на мобильных. Ориентация Android: portrait.

## Структура

Скрипты разложены по системам; подробнее — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
scenes/main.tscn                    # главный экран
scenes/blocks/placed_block.tscn     # модуль на поле (6×4)
scripts/autoload/game_state.gd      # фасад состояния (autoload)
scripts/core/game/                  # сервисы и модели
scripts/core/defs/block_defs.gd     # типы блоков и порты
scripts/systems/field/              # карта, камера, установка
scripts/systems/blocks/             # PlacedBlock, порты
scripts/systems/ui/                 # HUD и магазин
scripts/debug/debug_overlay.gd      # отладка (F3)
tests/unit/                         # unit-тесты
export_presets.cfg                  # пресеты Windows + Android
```
