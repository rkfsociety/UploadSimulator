# Upload Simulator

Казуальный симулятор ютубера: записывай ролики, собирай пайплайн из блоков на поле, зарабатывай просмотры.

Стек: **Godot 4.3+** (GDScript). Один проект собирается на **Windows** и позже на **Android** без переписывания логики.

Игра в **портретной ориентации** (720×1280): на ПК окно вертикальное, на Android экран зафиксирован в portrait.

## Быстрый старт (ПК)

1. Установи [Godot 4.3+](https://godotengine.org/download) (рекомендуется стандартная сборка).
2. Открой папку проекта: **Project → Import** → укажи `project.godot`.
3. Нажми **F5** (Play) — запустится главная сцена.

### Управление

| Действие | Как |
|----------|-----|
| Записать видео | Кнопка «Записать видео» (тратит энергию) |
| Магазин | Вкладки **«Блоки»** и **«Расходники»** — покупка модулей на склад, не улучшений |
| Поле | Панель под картой: выбери тип блока → клик по пустой клетке 5×6 |
| Улучшения | Кнопка **«Улучшить»** на самом блоке на поле (списывает кассу) |
| Пайплайн | **Загрузчик → Хранилище → Аплоудер** и **Аплоудер → Коллектор** через порты |
| Ячейки | Круг/кольцо = файлы, квадрат/ромб = деньги. Прямое связь загрузчик↔аплоудер или загрузчик↔коллектор запрещена |
| Соединение | Клик по выходу, затем по входу. Повтор по выходу — снять провод |
| 1. Скачать | Загрузчик качает из интернета **в хранилище** (нужна цепочка на поле) |
| 2. Выгрузить | Аплоудер берёт ролик **только из хранилища** |
| Деньги | Доход копится **в аплоудере**; **«Собрать в кассу»** через **Коллектор** |
| Касса | Только собранные деньги тратятся в магазине и на улучшения блоков |

Старт: по одному блоку каждого типа на складе, $80 в кассе. Провода игрок тянет сам.

## Сборка под Windows

1. **Project → Export…**
2. Выбери пресет **Windows Desktop** (уже в `export_presets.cfg`).
3. При первом запуске Godot попросит скачать export templates — согласись.
4. **Export Project** → файл появится в `build/UploadSimulator.exe`.

Из командной строки (если `godot` в PATH):

```bash
godot --headless --export-release "Windows Desktop" build/UploadSimulator.exe
```

## Сборка под Android (когда понадобится)

1. Установи **Android SDK**, **JDK 17** и пропиши пути в Godot:  
   **Editor → Editor Settings → Export → Android**
2. Создай debug keystore (Godot может сделать это сам при первом экспорте).
3. **Project → Export… → Android → Export Project**.
4. Установи APK на телефон или эмулятор.

Рендерер проекта: `gl_compatibility` — стабильный вариант для мобильных GPU. UI масштабируется (`canvas_items`, `keep_width`) + touch emulation с мыши на ПК. Ориентация Android: `screen/orientation=0` (portrait).

## Структура

```
scenes/main.tscn         # главный экран (поле + магазин)
scripts/game_state.gd    # поле, склад, провода, студия (autoload)
scripts/field_map.gd     # сетка, склад-кнопки, провода
scripts/placed_block.gd  # блок на поле + улучшение
scripts/block_defs.gd    # типы блоков, порты, правила связей
scripts/shop_menu.gd     # магазин: блоки и расходники
scripts/main_ui.gd       # кнопки студии
export_presets.cfg       # пресеты Windows + Android
```
