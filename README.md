# Upload Simulator

## Дорожная карта

- мобильная совместимость (тач, размеры кнопок, DPI) — **сделано**;
- сохранение прогресса на диск (`FileSaveBackend`, автосейв в `user://saves/`) — **сделано**; осталось UI выбора слотов (пока один слот по умолчанию);
- перетаскивание и снятие модулей с поля;
- новые типы файлов из интернета (изображения, архивы) и **свои загрузчики** под каждый тип;
- новые типы модулей в магазине ◆ (см. [docs/MODULES.md](docs/MODULES.md));
- способы заработка алмазов кроме выгрузки.

Казуальная игра про **передачу файлов в сети**: скачиваешь данные из интернета на диск, затем выгружаешь их обратно. Собираешь пайплайн из модулей на карте и зарабатываешь на выгрузке.

**Файлы из интернета** — пока в основном **текстовые** (**100 байт** каждый; лимит длительности передачи ~50 с на линии). Позже появятся другие типы (`FileDefs`).
**Стартовая скорость** канала «Сеть» (скачивание и выгрузка на 1-м уровне) — **8 байт/с** (далее растёт с улучшениями модуля и среды).
**Text Downloader** хранит скачанные файлы **внутри себя** (до **100 шт.**, лимит не увеличивается; модуль **нельзя улучшить**). Размер файла влияет на скорость передачи и доход.
**Лимиты баланса** (очереди, длительность заданий, размеры файлов, экономика) — в `resources/game_balance.tres`; для локальной подстройки скопируйте файл в `user://game_balance.tres` (см. `GameBalanceConfig`).

Стек: **Godot 4.6.x** (GDScript, в CI — **4.6.2**). Один проект собирается на **Windows** и позже на **Android** без переписывания логики.

Игра в **портретной ориентации** (720×1280): на ПК окно вертикальное, **без изменения размера** (ресайз и разворот на весь экран отключены); если монитор меньше — окно пропорционально уменьшается, но не выходит за рабочую область экрана. На Android — portrait.

## Суть игры

1. **Сеть** — канал в интернет; сам по себе файлы не качает и не грузит, только задаёт **скорость** (растёт с уровнем модуля).
2. **Text Downloader** — скачивает **текстовые** файлы из сети и **хранит до 100 шт.** внутри модуля (`net_out` сети → `net_in` загрузчика, `file_out` → `file_in` аплоудера). **Не улучшается.** Другие типы — отдельные загрузчики (см. `BlockDefs.file_type_id`).
3. **Аплоудер** — отправляет файлы из загрузчика в сеть (`net_out` → `net_in` сети); доход копится в его сейфе.
4. **Коллектор** — забирает сейф аплоудера в общий баланс $.

Цепочка файлов: **сеть → Text Downloader → аплоудер → сеть**. Деньги: **аплоудер → коллектор**.

## Быстрый старт (ПК)

1. Установи [Godot 4.6.x](https://godotengine.org/download) (стандартная сборка, не .NET).
2. Клонируй репозиторий или распакуй архив.
3. **Project → Import** → укажи `project.godot` в корне проекта.
4. Дождись первого импорта ассетов (папка `.godot/` создаётся локально).
5. **F5** (Play) — главная сцена `scenes/main.tscn`.

На Windows: **`run_game.bat`** — запуск игры без редактора (консольная сборка Godot из `Godot/`); при первом запуске автоматически выполняется импорт проекта. **`run_godot.bat`** — открыть проект в редакторе (ищет `Godot/Godot_v4.6.2-stable_win64.exe` в репозитории или `GODOT_EXE` в окружении).  
Подробно для **другого ПК**: [docs/SETUP.md](docs/SETUP.md).

### Управление

| Действие | Как |
|----------|-----|
| Карта | Перетаскивание — панорама, колесо / **pinch** — зум (ограниченный максимум, чтобы текст модулей оставался чётким). Кнопка с иконкой прицела — центр (0, 0). На Android/iOS — одним пальцем панорама/тап, двумя — зум |
| Магазин модулей | Кнопка корзины снизу — покупка блоков за **$**; после покупки модуль ставится в центр экрана |
| Магазин ◆ | Кнопка **◆** снизу: **открыть новый тип модуля** (потом купить за $ в корзине) и **улучшения среды** (каналы, диск); валюта **алмазы** (◆ за выгрузку) |
| Магазин модулей ($) | Только **уже открытые** в ◆ типы блоков |
| Поле | Модули **своего размера у каждого типа** (4–5×3 клетки, альбом; **«Сеть»** — 5×4); **«Сеть»** — отдельная панель со скоростями ↓/↑; улучшение **↑** — полоса снизу; порты на боках, соедини их проводами |
| Пайплайн | **Сеть → Text Downloader → Аплоудер → Сеть** (канал и файлы), **Аплоудер → Коллектор** (деньги) |
| Порты | Круг = файлы и канал (`net_*`) | Квадрат/ромб = деньги |
| Провода | Клик по выходу, затем по входу. Повтор по выходу — снять провод |
| Работа модулей | **Автоматически, без кнопок**: собранная цепочка сама скачивает, выгружает и собирает деньги |
| Сеть | Только скорость; нужны провода к загрузчику и от аплоудера |
| Скачивание | Text Downloader тянет текстовые файлы через сеть и кладёт в себя (до 100 шт.) |
| Выгрузка | Аплоудер забирает файлы из загрузчика и отправляет в сеть; доход в его сейфе |
| Деньги | Коллектор переводит сейф аплоудера в баланс (провод денег) |
| Улучшения | На модуле: **название**, **характеристики**, **текущее действие**; снизу — **улучшить → ур. N · $цена** (кроме Text Downloader) |

**Старт:** касса $280 (сеть, Text Downloader, аплоудер, коллектор). Модули покупаются в магазине; провода игрок прокладывает сам.

## Сборка под Windows

1. **Project → Export…**
2. Выбери пресет **Windows Desktop** (уже в `export_presets.cfg`).
3. При первом запуске Godot попросит скачать export templates — согласись.
4. **Export Project** → файл появится в `build/UploadSimulator.exe`.

Из командной строки (если `godot` в PATH):

```bash
godot --headless --export-release "Windows Desktop" build/UploadSimulator.exe
```

## Сборка под Android (когда понадобится)

1. Установи **Android SDK**, **JDK 17** и пропиши пути в Godot:  
   **Editor → Editor Settings → Export → Android**
2. Создай debug keystore (Godot может сделать это сам при первом экспорте).
3. **Project → Export… → Android → Export Project**.
4. Установи APK на телефон или эмулятор.

Рендерер проекта: `gl_compatibility` — стабильный вариант для мобильных GPU. UI масштабируется (`canvas_items`); autoload **`PlatformInfo`** определяет ОС, тач и плотность экрана (`content_scale_factor` на HiDPI). Интерактивные зоны — не меньше ~48 логических px; порты на карте имеют расширенную область нажатия. Ориентация Android: portrait.

## Структура

Скрипты по системам; подробнее — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
scenes/main.tscn                    # главный экран
scenes/blocks/placed_block.tscn     # модуль на поле (размер свой у каждого типа)
scripts/autoload/platform_info.gd   # платформа, тач, DPI (autoload)
scripts/autoload/game_state.gd      # фасад состояния (autoload)
scripts/core/game/                  # сервисы и модели
resources/game_balance.tres       # лимиты геймплея (очереди, генерация, экономика)
scripts/core/defs/block_defs.gd     # реестр типов блоков
scripts/core/defs/modules/          # описание каждого модуля (отдельный файл)
scripts/systems/field/              # карта, камера, установка
scripts/systems/blocks/             # PlacedBlock, порты
scripts/systems/ui/                 # HUD и магазин
scripts/debug/debug_overlay.gd      # отладка (F3)
tests/unit/                         # unit-тесты
export_presets.cfg                  # пресеты Windows + Android
```

В git **не** попадают только локальный кэш: `.godot/`, `build/`, `.cursor/`, `__pycache__/`. Всё остальное (сцены, скрипты, `*.import`, `*.gd.uid`) — в репозитории для clone без сюрпризов.
